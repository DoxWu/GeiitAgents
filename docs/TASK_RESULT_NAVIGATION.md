文档、图表、多步骤办公任务和可视化工作流均将过程/成果放在设置区之前。开始新的运行、切换任务或再次进入任务类型时，优先定位到当前过程/成果；流式增量及状态更新不会反复移动视口，用户可以继续查看设置或已有内容。

吸顶导航提供“过程与成果”和“任务设置 / 新建任务”（工作流显示“工作流设置 / 本次运行输入”）。复用输入、载入工作流定义和复制运行快照会定位到设置；表单保持挂载，以保留当前草稿。

多步骤任务和工作流运行中优先显示执行过程，结束后优先显示已保存成果，包括失败/中断时保留的部分成果。文档执行记录在运行中默认展开。多步骤任务的长总结折叠在成果后。

文档和工具成果的正文预览先于导出/编辑控件；预览区最大高度为视口的一半，可通过鼠标或键盘滚动查看长内容。窄屏历史列表限高并可独立滚动，给成果保留空间。生成内容和导出内容没有截断，也没有改变版本、加密存储或逐次云端授权。
