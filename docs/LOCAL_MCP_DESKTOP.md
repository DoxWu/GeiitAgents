# 桌面本机 MCP

Windows 桌面开发版 dev.80 起，工作台的「任务 → 资源仓库 → 新建 MCP」可以安装 npm/Python 包并通过 stdio 连接。本机连接属于当前密钥库的私有能力，可以绑定到智能体，再用于手动文档任务或长任务。

## 使用步骤

1. 在电脑上安装 Node.js（含 npm），或 Python（含 pip 和 venv），加入 PATH 后重启应用。应用不自动安装运行时，不支持 Microsoft Store 的 Python 跳转入口。
2. 新建 MCP，选择「本机 stdio」，填写包名和精确版本后安装。npm 版本如 `1.2.3`，不接受 `latest`、范围、Git/文件路径；Python 同样填写确定的版本。
3. 选择包暴露的命令入口。启动参数每行一项，直接作为 argv 传递；例如文件系统 MCP 可填允许访问的测试目录。环境变量填写字符串 JSON 对象，勿把真实凭据填到用途说明或技能指令中。
4. 点击「连接并发现工具」，确认本机进程启动说明，选择工具并加密保存。简单参数自动映射为输入字段；嵌套对象、数组等使用 `arguments` JSON 字符串。输出统一为 `result` 字符串，其中可包含 JSON。
5. 在智能体仓库勾选该能力并保存，再将智能体加入手动任务。运行前会显示包名、工具清单和本机权限说明，按任务授权；工具返回值按不可信任务数据处理。

## 安装与执行范围

- 包安装在应用数据目录下的独立目录。npm 使用 npmjs.org，禁用生命周期脚本；Python 默认使用 PyPI，也可切换至阿里云 PyPI 镜像，在独立 venv 中仅安装 wheel，不构建源码。来源由应用固定选择，不接受自定义 URL。依赖仍由包管理器按包元数据解析；需信任发布者及依赖。需要编译或安装脚本的包可能不能使用。
- 启动目录固定为应用管理的包目录；不使用 shell。继承环境经过清理，只保留必要的系统路径和用户明确填写的变量；禁止覆盖 PATH、运行时注入变量及包管理器配置。
- **MCP 包是当前 Windows 用户权限下的进程，不是沙箱。** 参数或环境清理不能限制其文件、网络和服务访问权限。仅安装和启动可信包。
- 安装最长 10 分钟，可随时取消；工具发现 25 秒，单次工具调用 30 秒。最多同时安装一个包、执行两项发现/调用，安装不占用工具调用槽位。超限明确返回忙碌，不在本机无界排队。
- 任务结束、取消、锁库和退出会关闭相应会话，Windows Job 管理其子进程。包目录保留以便再次运行；「移除安装包」删除对应安装，不删除已保存的智能体快照。
- 支持 MCP 初始化、工具分页发现和调用；服务端要求的客户端采样、交互式授权、roots 等能力不在此版本中。依赖外部程序、特殊入口、GPU 或额外 PATH 的服务可能需要后续适配。

## 共享、备份和提示

本机连接不可发布到共有或组织能力/智能体仓库；含本机连接的工作流不可共享、导出为明文工作流文件，也不可配置定时或事件触发。恢复旧触发器时会禁用相应项目，等待用户手动处理。

本机密钥库会加密保存参数和环境变量。加密工作台备份默认排除模型 Key、本机 MCP 参数及环境变量；明确勾选包含凭据后才一并导出。备份不包含包文件或运行时。换电脑后需重新安装、发现和保存工具，并重新绑定智能体/工作流的固定快照；原机器的安装 ID 不会自动映射到新机器。

说明气泡使用工作台主题色，支持鼠标悬停、键盘聚焦、点击及 Esc 关闭；重要错误、运行状态、发送数据的授权和覆盖恢复确认继续直接显示。
