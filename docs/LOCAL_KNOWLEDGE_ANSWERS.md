# 本地知识库回答生成

更新：2026-09-20。已实现本地检索后按来源生成回答，不改变本地向量模型或现有云端知识库。

## 使用与边界

检索完成后，在结果下方解锁工作台密钥库，选择生成模型及 1–5 个片段。可用模型包括已保存的本机/个人云端连接，以及检查权限后可用的账号云端模型。模型不会默认选择或自动请求。

发送内容只有当次检索问题、所选原文、文件名、字符位置和来源编号，不发送向量、整个库或其他聊天记录。云端连接每次请求必须重新授权；切换模型或来源清除授权。本机接口是否在内部联网取决于用户自己的服务配置。失败不静默更换模型。

回答和来源原文显示在当前页面，不自动写聊天记录或知识库。重新检索、关闭本地模型、离开页面时停止请求并清除结果；密钥库锁定停止请求，登出停止云端请求。供应商已收到的请求可能继续执行。输入框之后修改的问题不会替换旧检索结果对应的问题快照。

## 实现

- `frontend/src/localKnowledge/answer.ts` 构造 system + JSON user 消息，将来源明确标为不可信资料，要求只依据资料作答、资料不足时说明、标注 `[n]` 引用。不支持工具调用。
- `LocalKnowledgeAnswer.tsx` 提供模型选择、来源选择和逐次出站授权，回答按纯文本展示，附来源原文，不执行 HTML/远程图片。
- `workbenchStore.answerKnowledge` 复用密钥库及现有 `completeModel` / `completeAccountModel`，Key 不进入公共状态，不创建持久对话。120 秒超时，取消及锁定时忽略迟到响应。
- 问题最多 4096 字符；问题加来源文本/文件名合计最多 24000 字符。最大输出 Token 沿用生成连接的可选设置，默认不配置；与 E5 输入上限无关。
- 模型引用仍须核对原文，提示规则不是绝对抵抗提示注入或事实正确性的保证。暂未实现流式回答、回答导出、保存为独立对话。

## 真实验证

用户明确授权读取 `backend/.env` 凭据。本机 helper 只读取所需模型字段，不初始化数据库，不修改 `.env`，不输出/保存凭据或供应商原始错误。只发送虚构报销制度和合成连通性问题。

主配置 `OPENAI_API_*` / `LLM_MODEL_NAME` 当前 HTTP 403，原因尚未确认。显式设置测试进程 `LOCAL_ANSWER_PROVIDER=configured-fallback` 使用 `.env` 中 `LLM_FALLBACK_*` 后成功；这仅影响测试脚本，不改变产品模型回退行为。

`scripts/verify-local-answer-live.mjs` 已通过真实 E5/WASM 检索、界面授权、现有后端 `complete_private` 函数和真实供应商回复。回复含发票、付款凭证、主管审批记录、十个工作日和 `[1]` 来源。账号认证/可用性使用 fixture，**不是生产登录或完整 FastAPI 权限链验证**。Python helper 不把 Key 传给浏览器，仅返回合成回答与测试模型标签。`LOCAL_ANSWER_MOCK=1` 为单独标记的生成模拟模式。

本轮相关前端 70 项通过（此前 61 项 + 新增回答 9 项），TypeScript、相关 ESLint、Web/开发桌面构建通过。证据在 `.tools/local-answer-qa/`；真实与模拟结果分开记录，不提交截图/模型缓存。Windows 包递增 `0.1.0-dev.2`；本批真实生成验证在 Chromium，未重跑原生生成端到端、后端全量、低配/大语料基准或安装/卸载。
