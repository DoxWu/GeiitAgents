# 多步骤办公任务

更新：2026-10-02。本批为本地实现和验收，未推送或部署。

## 用户流程

工作台 → 任务 → 多步骤任务，填写目标，选择已有模型，可选导入或粘贴 MD/TXT/DOCX/PPTX/PDF 参考材料与 CSV/XLSX。DOCX 在本机从 Word 正文提取可见段落、标题、列表和表格为 Markdown，压缩包最多 2 MB、解压最多 12 MB；不保留页面/样式，图片、页眉页脚、脚注、尾注、批注、嵌套/合并表格等未完整支持时显示提示。PPTX 按演示文稿关系顺序提取最多 120 页的文本与基本表格，压缩包最多 5 MB、总解压最多 25 MB；图片、图表数据、演讲者备注和批注不导入并显示提示，不保留版式、动画或图像内容。PDF 使用懒加载的 PDF.js 在本机按页提取最多 100 页可选中文本，文件最多 10 MB、结果最多 50,000 字符；扫描页不做 OCR，版式、图片、表单和批注不保留并显示提示。PDF 主解析器与 Worker 在用户导入 PDF 时才加载。客户端不上传文档二进制。XLSX 只导入首个可见工作表，复用图表导入的 2 MB ZIP/XML/单元格上限以及公式、错误单元格和合并格拒绝规则；原始工作簿不会持久保存。模型通过实际 `tool_calls` 协议提出工具调用，客户端校验、执行并回传工具结果，最后显示总结与多个成果。纯文本声称“完成”但没有生成任何成果时，任务失败并提示检查模型的工具调用支持。

任务历史、输入、工具参数/结果及成果沿用本机加密库。可查看每一步、停止、复用输入创建新任务、选择和下载成果；Markdown 可在本机导出 Word，并可选经典 Letter、商务报告 A4 或会议纪要 A4 样式。导出时还可单独覆盖纸张（A4/Letter）、字体（微软雅黑/Aptos/Arial/Times New Roman）、字号（10–16 pt 受限选项）、行距（1–2 倍）和页边距（0.5–1.5 英寸）；留空沿用所选样式默认值，不修改 Markdown 源文。有效选项及转换器版本写入加密导出历史。每个 Markdown 成果有独立的编辑/比较/恢复版本链，相同文件名的多个成果也相互隔离。修改成果不改变原工具检查点或触发模型，任务检查点和用户编辑都保存在加密工作台备份内。失败、中断和取消任务保留已保存成果，需要用户核对。成果不会自动写入外部目录；下载仍由用户操作。

## 固定工具与边界

| 工具 | 参数 | 结果与权限 |
| --- | --- | --- |
| `inspect_csv` | 空对象 | 返回本次提供的 CSV 表头、原始行；不读取其他文件 |
| `render_chart` | title、category_column、value_columns、chart_type、unit | 基于任务原始 CSV 生成 SVG；列从 0 开始，1–6 个数值系列，柱状或折线；模型不能替换数据 |
| `create_document` | title、markdown | 创建新的 Markdown 成果，标题最多 80 字符、正文最多 50000 字符；不编辑用户外部文件 |
| `search_wikipedia` | query | 仅在用户勾选本次联网授权后出现；查询中文维基百科，最多 5 条结果、每任务最多 3 次；摘要和固定来源链接是不可信参考资料 |

- 参考材料最多 50000 字符，CSV 最多 100000 字符、50 行、12 列；文件导入按 UTF-8 解码并检查字节限制。

## 本机 PDF 参考文本（dev.59）

- 仅在用户选取 PDF 时动态加载 PDF.js 和 Worker；本机读取可选中文本并按页写入当前任务参考材料。PDF 二进制不上传或保存，之后的云端任务仍要求用户单独授权发送文本。
- 限制文件 10 MB、100 页、50,000 字符；密码保护、损坏或无文本 PDF 明确拒绝。扫描页会提示未提供 OCR，其他页面内容只保留提取文本，不保留视觉版式、图像、表单或批注。
- PDF 主模块约 364 KB、Worker 约 1.38 MB（未压缩）；不会进入初始应用 chunk，但桌面安装包需要携带资源。实际增量以 dev.59 安装包记录为准。
- 联网搜索词最多 200 字符，只请求固定的中文维基百科 API；响应最多 128 KiB、20 秒超时，不发送 cookies、不跟随重定向。授权提示用户搜索词可能包含任务材料，需确认适合公开查询。
- 模型每次最多返回 4 个调用，任务最多 6 轮请求、8 次工具执行；单轮客户端 2 分钟、整任务 6 分钟，原生 HTTP 115 秒。服务端 HTTP 阶段总超时 120 秒，公网地址解析另有既有超时。
- 最多 50 条消息，序列化上下文约 200000 字符；每条正文/参数最多 100000 字符，上游响应最多 2 MiB。Unicode 字符在不同运行时计数略有差异，客户端先按 UTF-16 校验。
- 未知工具、重复调用 ID、缺少工具结果或错误消息顺序直接拒绝。已知工具的无效参数作为 `{ok:false,error}` 回传，模型可以在原限额内纠正。
- 参考资料与工具结果视为不可信数据。执行权限由固定工具注册和本机参数校验控制，不依靠提示词赋予权限。不支持读取任意目录、脚本、邮件发送、任意 URL 或任意第三方工具。网页搜索仅限用户明确授权的中文维基百科。

## 模型接口

| 路径 | 请求和认证 |
| --- | --- |
| Web 本机 | 回环地址 `/chat/completions`，兼容 `tools`、`tool_choice:auto`、`stream:false`；不带浏览器 cookies、不跟随重定向 |
| Tauri 本机 | `complete_local_tools({requestId,baseUrl,apiKey,body})`；Rust 验证回环 URL、请求字段/顺序/限额，经 HTTP 返回白名单结果；桥接不执行工具 |
| 个人云端 | `POST /api/v1/private-models/tools/complete`，活跃账号；body 为 base_url、model、messages、可选 max_tokens 和用户授权时的 `allow_web_search`；用户 Key 仅在 `X-Model-Api-Key` 请求头中临时转发 |
| 账号云端 | `POST /api/v1/private-models/account/tools/complete`，沿用账号权限；body 为 messages 和用户授权时的 `allow_web_search`，客户端不能替换服务端模型或传 Key |

两个服务端接口分别每分钟 20 次限流，返回 `{content,tool_calls,model}`；非法请求、路由内错误与成功响应带 `no-store`，认证/全局限流沿用原中间件。响应工具调用只保留 id/type/function.name/function.arguments，供应商附加元数据剥离；请求仍严格拒绝额外字段。默认不发送 `max_tokens`。

个人云端沿用公网 HTTPS、DNS 固定 IP、禁用环境代理与重定向的传输。账号云端复用现有模型配置，以独立 `ChatOpenAI` 工具实例禁止 SDK 自动重试，再做请求内 `bind_tools`；不改变原有知识库模型调用，也不自动改用其他个人连接。模型名或目录条目不表示工具能力，尚无持久能力登记；用户选择的模型必须实际支持兼容工具协议。

## 授权、保存和中断

云端任务必须勾选授权本次最多 6 轮发送目标、参考资料、CSV 工具结果及生成内容。修改输入、所选连接配置、账号或模型会清除授权，提交后消费授权。API Key 本机加密，服务端不保存个人任务或个人 Key。

每次模型请求和工具执行的开始、结果均先做加密检查点；保存失败就停止后续调用，提供“重试本机保存”，不会自动重放模型或工具。已经生成且仍在内存中的成果会保留，最终状态保存失败也必须查看保存错误；未成功写入的部分在关闭客户端后可能丢失。

取消通过 AbortSignal 传递，原生通过独立 requestId 撤销 HTTP；锁库清空内存并阻止迟到回写，账号退出会取消云端任务。刷新解锁后，原 running 记录变为 interrupted，只恢复记录与成果，不自动续跑。服务端普通 HTTP handler 不保证客户端断开时立即取消已发出的供应商请求，取消不能撤回已发送数据或已发生的计费。
