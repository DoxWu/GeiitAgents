# 授权目录批量文本编辑与恢复

更新：2026-09-29，dev.18。入口为“文件整理 → 批量文本编辑”。本功能在本机处理用户主动选中的文本，不调用模型或上传内容；没有新增依赖、通用文件权限、服务端接口或后台触发器。

## 使用范围

- 用户选择一个目录，再逐个勾选最多 **20 个**可见 MD/TXT 文件；不递归，目录最多列出 500 个可见文本文件。
- 单文件仍为 **256 KiB UTF-8**，拒绝无效编码、二进制控制字符和未配对代理字符。匹配区分大小写，使用字面内容，不使用正则或替换变量；`$&` 等按原文写入。查找不可为空，查找/替换分别最多 10000 字符。
- 多行查找以 LF 表示，读取时规范化为 LF 进行匹配；实际写入保留原 BOM，并默认保留各文件换行。混合换行文件发生修改时必须显式选择 LF/CRLF/CR。历史恢复保留确切字节，包括混合换行。
- 读取/转换失败、无匹配或没有变化的文件不能勾选写入。转换前限制预期字符增长，转换后按真实 UTF-8 字节复核，防止大量匹配导致巨大临时字符串。
- 页面展示每文件状态/匹配数，逐个查看差异和完整前后文本。差异算法沿用单文件有界比较，最多显示 400 行；超过范围提示检查完整文本。改变规则/文件选择使旧预览失效，修改应用选择清除确认勾选。

预览与规则是临时状态，离页、取消、锁库后需要重新读取。单文件编辑草稿存在时不能启动批量编辑，需先完成或明确丢弃。浏览器恢复历史时仍需重新选目录并确认身份，名称不是身份证明；原生使用目录/文件身份摘要。

## 执行与故障

1. 确认时核对完整文本历史基线、选择集合、原目录句柄；任何历史变化使预览失效。
2. 整个预检查和批次写入持有现有文件操作锁，与移动/撤销及单文件读写互斥。先复核全部所选文件的身份和摘要；任一个不一致，零文件写入。
3. 预先检查全部新版本的容量，再一次加入全部前后快照，状态为 `not-started`，加密保存成功后才允许写盘。预览此时已消费，不能重复提交。
4. 逐文件复核，先保存 `running` 检查点，写入并读回校验后保存 `succeeded`；任一文件失败、取消或持久化失败就停止后续文件。
5. 已完成文件不会自动回滚。当前已发出的原生写入可能完成；未发出的条目保持 `not-started`，结果不明的条目标记 `needs-attention`，刷新后遗留 `running` 转 `interrupted`。

这不是多文件事务，不能保证断电后整批一致。浏览器最后复核到提交仍存在外部进程竞态；原生复用单文件有锁写入/故障回滚，也不是断电原子替换。操作期间应避免其他程序编辑同一文件。

存储失败时保留当前内存状态。“重试批次记录保存”只写密钥库，不继续批次或重放已完成写入。若无法保存，可用工作台加密备份导出内存快照；重开只能恢复最后成功保存的检查点。锁库后，旧原生操作真正结束前仍保持进程操作锁，不允许另一个文件操作。

## 核验、恢复与历史

- 每个文件仍使用 `FileEditVersion`，新增可选 `batch: { id, index, total }`；新状态 `not-started` 表示未发出写入。没有重复保存一份批次正文。
- 共用现有最多 **50 条、前后文本合计 2 MiB** 的历史额度，不自动淘汰；localStorage 可能更早耗尽。预检查一次性检查全批容量，不允许先写几个再因历史条数不足停下。
- 批次历史按批次标识分组，展示仍保留条数/原始总数和每文件状态。单文件历史继续支持导出、核验、单独恢复和删除。未执行记录可以明确删除；未核验的中断/不明记录仍不能删除。
- “核验批次文件”逐条只读比较当前身份/摘要；某条无法读取时停止并报告，已完成的核验保留。未执行条目即使当前恰巧与新文一致，也仍保持未执行状态，不把外部编辑当作本批写入。
- “预览恢复批次原文”只选择**当前身份和摘要仍与原批次写入版一致**的文件；外部修改、已是原文、未执行、缺失或无法读取的条目提示并不恢复。再次确认后创建新批次/新版本，保留原历史和被替换的当前文本，不自动重放旧批次。
- 批次明文 JSON 导出含当前保留的前后文本、摘要及状态，供人工恢复查阅；没有该格式的自动导入/执行入口。完整迁移使用 [.geiitwork 加密备份](WORKBENCH_BACKUP.md)，其校验已覆盖批次字段、索引/数量/目录一致性和重复条目；允许用户删除后只剩部分历史，不要求补齐旧记录。

含批次字段或 `not-started` 的加密备份需要 **dev.18+** 恢复，旧版严格拒绝未知字段。备份恢复不取得外部目录权限，也不写外部文件。

dev.19 新增 [历史分页与检索](FILE_HISTORY_NAVIGATION.md)，每页 10 个批次，展开后才加载详情。搜索与状态须命中同一文件，但显示/核验/恢复/导出仍使用该批次完整保留记录；筛选不会截断批次，也不改变批次编号或存储结构。

- 新增域/状态/UI 17 项：字面替换、编码/换行/增长限制、整批容量与过期历史、共享锁/身份、批次恢复、配额失败零写盘/不重放、部分失败、取消/迟到读取、跨锁库在途原生写入隔离和备份校验。
- `frontend/scripts/verify-file-text-batch.mjs --web` 使用真实 Chromium OPFS，选择器为测试注入；不能视为 Web 外部目录授权已实测。
- 同脚本默认运行最终开发 exe，通过真实 Windows 系统选择器选择 `.tools` 合成目录，再使用 WebView2/Rust 读写；没有注入目录授权或任意路径 IPC。
- 脚本核对三文件 BOM/CRLF/中文/emoji 替换与恢复、实际导出字节、外部修改时零写入、首文件完成后存储失败导致其余未执行、仅保存重试、刷新后只读核验及部分恢复；每模式预期恰好 8 次文件写入。Web 另验 390px。
