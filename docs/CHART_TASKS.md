# 本地图表任务

更新：2026-10-02。支持 CSV 和受限 XLSX 导入，多系列柱状/水平条形/折线图及单系列饼图；图表可保存、下载 SVG/PNG/XLSX 数据并纳入加密备份恢复。Windows 原生路径仍需本批单独验收。

## 使用与范围

工作台 → 任务 → 图表工具。粘贴或导入 UTF-8 CSV/XLSX，选择分类列，勾选 1–6 个数值列，选择分组柱状图、水平条形图或折线图；饼图只允许一个数值列。XLSX 只读取第一个可见工作表并显示表名；隐藏工作表不会被选中。填写标题和可选单位；先“检查并预览”，再“保存图表任务”。数值系列按勾选顺序绘制，共用单位和坐标轴。修改输入会清除检查快照，必须重新检查。历史任务支持查看、复用输入、删除及下载 SVG/PNG/XLSX 数据。

全部在本机执行，不上传数据、不调用聊天或向量模型、不读写知识库。支持最多 6 个数值系列、50 条数据、12 列、100000 字符；CSV 不超过 400 KB，XLSX 不超过 2 MB、256 个 ZIP 条目、12 MB 声明/读取解压数据、8 MB 单条目、2000 字符单元格。单元格、公式、错误值、合并单元格、无效 XML/关系和不安全路径会拒绝；公式单元格不使用缓存结果。XLSX 共享字符串、内联字符串、布尔值和数值可导入；日期序列按表格中的原始值处理，不推断格式。标题最多 80 字符，单位最多 20 字符，表头和分类标签最多 60 字符。中文 Windows 字体优先，其他系统使用字体回退。

## 检查与表达

- CSV 支持 BOM、CRLF/LF、引号转义和含逗号/换行的引号单元格；拒绝引号错误、列数不一致、重复/空表头和空行。分类标签、表头、标题和单位不能包含换行。
- 数值只接受十进制小数或科学计数法；拒绝缺失值、公式、百分号、千位分隔符、非有限数以及超限值。范围为绝对值 `1e-9` 至 `1e12`，或零；不猜测地区格式、补值或自动汇总。
- 重复分类、负值、全零、未填单位、大数值跨度及单点折线提供提示。折线按输入顺序等间距连接，不会把日期转换为时间轴。
- 每个选中系列单独校验，错误标明列名和行号；拒绝空选择、重复列、分类/数值列相同和超过 6 个系列，不静默丢弃或回退。跨系列量纲一致性由用户确认；数值跨度超过 1000 倍时提示拆图。
- 分组柱状图不堆叠，多折线共用分类坐标；每个系列固定颜色，负值仍使用其系列颜色，通过零线方向区分。长图例会缩写，完整列名保留在 SVG 标题和数据表中；多系列不叠加点值文字，避免文本重叠。
- 水平条形图按 CSV 输入顺序排列分类，多系列在每个类别内分组绘制，共用有正负数值轴和零基线；长分类标签在 SVG 中截断显示并通过条目标题保留完整文本，不自动排序或汇总。
- 坐标轴保留零基线；过长标签/数值可缩写，完整数值可在界面数据表、SVG 描述和点位标题中读取。窄屏保持图形尺寸，在预览容器内横向滚动。
- 检查针对数据格式与表达风险，不判断业务真实性，不识别已有图表图片，也不进行统计推断。

## 持久与隐私

`chart.generate` 复用本机加密密钥库，保存转换后的 CSV 输入、TaskRun、`chart.check` / `chart.render` 工具记录、检查提示和 SVG 成果。原始 XLSX 仅在导入期间读取，不会另存至任务记录。成果带 SHA-256，工具记录保存渲染器版本 `local-chart/4`；不含可执行脚本、外部图片或链接，预览使用图片 Blob URL。加密备份校验支持柱状、水平条形、折线和饼图 SVG 元素；未知 SVG 标签或属性仍会拒绝导入。

旧任务缺少 `valueColumns` 时使用原 `valueColumn`，已有 SVG 下载仍使用原字节；新任务的 `valueColumns` 保存系列顺序，`valueColumn` 为首个系列。异步保存前复制数组，避免界面后续修改污染任务快照。复用旧任务和载入新 CSV 时清除上一份输入的多选状态。

先持久化运行记录，再生成成果并保存。初始写入失败停止生成；最终写入失败保留内存成果供下载/重试，并显示存储错误。相同请求标识和输入重试不重复创建成果；改变输入需要新标识。锁定后忽略迟到结果；重新打开时未完成任务按既有机制标记中断，不自动重放。图表与文档列表分别展示，SVG 不可走 Markdown 编辑/恢复或 DOCX 导出路径。

SVG 下载使用保存的原始字节；PNG 是该 SVG 的本机 2 倍尺寸栅格化结果，不另存 PNG 二进制或工具记录。源 SVG 面积限 250 万像素，对应输出画布最多 1000 万像素；超限可下载 SVG。下载文件为明文。未保存输入离开页签/锁定后丢弃，本机加密库存储配额和旧客户端回写兼容风险仍需注意。
