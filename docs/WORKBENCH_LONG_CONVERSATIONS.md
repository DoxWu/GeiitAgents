# 工作台长对话分页

工作台本机对话仍将完整消息保存在加密库，发送模型时也使用完整上下文，Markdown 导出包含完整对话。为了降低长会话在低配设备上的首屏 DOM 和 Markdown 渲染开销，界面默认只挂载最近 20 条消息。

点击“加载更早的消息”后，每次再显示 20 条；加载旧消息会保留滚动位置，避免页面跳动。切换对话或收到新消息时回到最近一页。分页只控制显示，不删除、截断或重排已保存消息。

当前对话仍受工作台既有消息数、文本长度和加密快照上限约束；这项分页不是无限上下文或服务端历史分页。模型上下文窗口仍由服务商实际限制决定。

本地验证覆盖 45 条和 30 条合成消息、逐页加载、对话切换和旧消息保留。未调用真实模型、未访问生产数据；真实 WebView2 的滚动性能和 8 GB 设备压测仍待后续验收。
