# 图片任务、画布尺寸与构图验收（2026-11-02）

## 已实现的行为

- 图片生成增加可命名的独立任务，支持新建、选择、复制和确认删除。每个任务分别保存提示词、区域、画布宽高/背景、参考图和生成结果；切换前保存当前任务，切换取消生图，迟到响应不能写入其他任务。任务最多50个，继续使用本机加密库及统一8 MiB图片预算，单张图片上限1,500,000字节。
- 新任务从1024×1024画布、空提示词及一个无描述的示意区域开始。旧单草稿首次保存迁移为“原有构图”，保留人物、素材和16:9几何关系，按1536×864解释旧画布。复制获得新任务ID，不共享可变草稿对象。
- 支持七种比例预设、自定义宽高及背景颜色。宽高为512–2048之间的16的倍数；输入后点击应用尺寸。预览、构图截图和本机/浏览器/BYOK/服务端生图请求使用同一尺寸，主备端点保留该尺寸；不支持所选尺寸的供应商仍可能拒绝请求。
- 最终生图提示词自动附加画布尺寸/底色、区域百分比坐标与大小、旋转、层号、描述和指定文字。界面可查看实际发送内容。修复过去预览16:9而请求固定1024×1024、直接生图遗漏区域参数的情况；最终提示词最多6000字符，超限明确提示，不静默截断布局。
- 画布和属性网格分别按内容布局，限制最小宽度并裁切越界旋转区域，防止画布延伸覆盖表单；PPT共用编辑器默认仍为16:9。
- 自动保存由工作台管理，锁库前提交最后一次编辑；加密备份捕获仍在等待保存的图片任务，存储失败可导出保护数据。失败保存/删除保留原任务；锁库清空内存任务。修复重新打开已有任务但未编辑时，首次生成结果可能被错误的组件代次判断丢弃。
