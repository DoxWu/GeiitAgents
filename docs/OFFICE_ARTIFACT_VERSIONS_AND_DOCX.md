# 文档成果版本与本地 DOCX 导出

更新：2026-09-23。已实现应用代码、单元测试、浏览器操作验证及开发包构建；未发布、未部署。Word/LibreOffice 实际分页渲染尚未验收，不把 OOXML 检查当作版式验收。

## 使用与数据

- 工作台 → 任务 → 已完成成果：可查看各版本、编辑最新版本、保存新版本，下载所选版本的 Markdown 或 DOCX。
- 手动编辑逐字保留内容，不剥离代码围栏或尾部空白。新成果记录 `parentArtifactId`、递增版本、独立 SHA-256；旧成果不覆盖。相同内容不重复创建版本，每个任务最多 50 个版本。
- 编辑结果与 `document.edit` ToolRun 一起进入既有本机 AES-GCM 加密库。编辑草稿只在当前页面内存，离开页签/任务或锁定会丢弃，页面明确提示，关闭页面时提示未保存修改。
- `document.export-docx` ToolRun 记录源成果 ID、文件名、字节 SHA-256、转换器版本和格式降级提示。状态成功表示转换完成且记录保存，不保证用户最终保留下载文件。
- DOCX 二进制只在转换/下载时短暂存在内存，不写入 localStorage，也不作为 Base64 重复存储。再次导出会按所选源版本重新转换；ZIP/文档元数据可随生成时间改变，不保证逐字节相同。每任务最多 100 次导出记录。
- 所有导出文件均为明文。整个转换不发送模型请求、不读写知识库、不上传文档；链接/图片不生成外部关系，不抓取 URL。

## 转换范围与轻量化

使用 `docx` + `unified`/`remark-parse`/GFM，在独立 Worker 内解析和打包。用户点击导出后才导入客户端并启动 Worker，完成/失败/超时/锁定后终止；30 秒上限。导出最大 200000 字符、15000 个 AST 节点、32 层 AST 深度、9 层列表，表格最多 8 列/2000 个单元格，超过限制明确拒绝，不截断内容。

支持标题（首个一级标题用 Word Title）、正文、粗体/斜体/删除线、行内与块代码、列表起始编号与嵌套、任务复选标记、GFM 表格。Letter 纵向、1 英寸边距、11 pt 正文、中文微软雅黑字体提示、黑色标题、浅灰表头/边框和跨页重复表头。未嵌入字体，不同系统的字体替代和版式仍需实测。

链接输出文字和地址，图片输出说明和地址，HTML 原文显示，引用转普通段落，脚注转编号和段落。转换成功后显示降级说明并存入工具记录。没有可视 Word 编辑、模板选择、图片嵌入、PDF 转换、原始 DOCX 导入或排版保真承诺。

最终 Vite 产物：DOCX Worker 497.73 kB，按需客户端 0.61 kB；浏览器验证首次导出前未请求这两个组件。字符解码器的 browser 入口会引用 `document`，导致 Worker 启动失败，已在 Vite 中映射到无 DOM 的字符表入口；同时使现有 Markdown chunk 从约 335.97 kB 增至 364.60 kB（gzip 约 102.15 → 114.38 kB）。未签名 dev.5 NSIS 包为 7,835,014 字节，比 dev.4 增加 655,140 字节（约 9.1%）；这是整体产物差值，包含代码及源映射，不是纯库大小。不会默认下载本地向量模型。

## 失败与恢复

- 保存/导出在首次异步操作前占用任务级互斥锁，并拒绝并发编辑、导出和删除。编辑旧版本需要先切回最新版本，不隐式分叉。
- 哈希、加密、动态加载、Worker 返回后检查密钥库代际和锁定状态；锁定时终止 Worker，丢弃迟到结果，不重新填充内存或触发下载。
- 版本写入失败时保留内存版本和草稿，显示存储错误；相同编辑再次保存不会重复创建版本，也可“重试本机保存”。刷新前应重试保存或下载重要内容，内存成果不等于持久成功。
- 导出开始前保存 running 工具记录，失败标记工具而不改变已完成生成任务或删除 Markdown。重开解锁修复 running 工具为 interrupted，不自动重放。最终记录写入失败不返回可下载结果，可重试转换。
- 锁定或页面退出仍有可能留下已完成转换的工具记录但没有触发下载；记录不意味着文件已保存到磁盘。切换页签会停止当前 UI 的下载动作，任务记录仍可查看，再次导出即可。
- 密钥库仍受浏览器存储配额约束；本轮没有迁移到文件系统/IndexedDB 二进制仓库。旧客户端不理解新字段，回退旧包前应导出重要内容，避免旧写入路径丢失新记录。

## 2026-09-23 版本对比与恢复

“对比版本”默认以父版本为基准，允许选择其他基准，方向始终为基准 → 所选。按 Markdown 原文比较增删行，保留 CRLF/LF、空白和缺失末尾换行；内容作为纯文本显示。默认隐藏未变化行，每页 100 行，每行显示前 2000 字符并明确提示。合计超过 400000 字符或 10000 行时只报告内容不同并建议下载；中间 LCS 矩阵超过百万单元格时按整段替换显示，提示不是最小差异。最大矩阵约 2 MB，不引入新依赖，不调用模型。

“恢复为新版本”把旧版本内容复制为最新版本，确认绑定当前最新 ID。比如 v1 → v3：v3.parentArtifactId = v2，v3.restoredFromArtifactId = v1；新增 document.restore ToolRun 记录源 v1、前版本 v2、结果 v3。保留 v1/v2，后续编辑 v3 成 v4 时不继承恢复标记。过期确认和跨任务错误拒绝；相同内容不新增版本；最多 50 版本。编辑/恢复共用任务锁、代际检查与加密保存路径，失败可保留内存重试，重试本身也持有任务锁。
