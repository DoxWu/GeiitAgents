## 2. 长任务：两种视图，一份流程

### 用户流程

1. 从任务描述、已有流程或空白草稿开始。描述转流程后先展示草稿，用户确认步骤与调用范围。
2. 从可见的智能体仓库添加已有智能体，也可添加文档生成、图表、函数判断、智能体判断、触发事件、成果汇总等节点。第三版演示手动、定时、文件加入、Webhook 和任务完成五类触发入口；文档 / 图表独立节点仍待实施。
3. 在“步骤列表”和“流程画布”之间切换；名称、输入、配置、连接关系同步。节点可自由拖动，支持坐标输入、方向键微调和画布缩放；从出口拖向目标入口，或依次点击两个端口生成箭头。箭头可选中删除，判断节点分别使用“满足 / 不满足”出口。
4. 选中节点后设置具体要求，将任务输入或上游输出字段映射到智能体输入。
5. 运行前检查依赖、类型、权限、模型连接、调用预算和必要授权。
6. 运行时展示排队、处理中、待确认、失败、取消、完成状态及节点产物；成果优先展示，过程可展开。

### 实施约束

- 采用现有 `WorkflowDefinition` 作为统一流程骨架，新增版本化适配层；不维护两套执行引擎。旧多步骤任务的自由工具调用模式可先迁为一个兼容节点，历史记录保持原样可读。
- 简单顺序流程用列表即可；分支在列表中保留条件与去向，在画布中显示箭头，不能切到列表时丢失拓扑。列表重排只改变展示顺序，不自动重接箭头。第三版已经演示分支编辑；当前每个普通出口最多一条箭头，判断有 true / false 两个出口；尚未演示并行扇出、循环、断点和失败重试编辑。有界循环需显式循环节点、迭代与预算限制，不允许用任意回边隐式形成无限循环。
- 函数判断接收声明的输入变量并返回布尔值；实施时使用受限表达式解析器或已批准的函数资源，限制函数集合、输入大小与执行时间，不直接 `eval` 用户表达式。原型只记录表达式文本，按用户选定的演示结果分支；示例 `length(context) >= 200` 不实际执行。
- 智能体判断引用已有智能体的稳定 ID / 版本，单独要求 `decision: boolean` 与 `reason: string`。普通文字输出不能直接视为真值；类型错误、超时或无结论进入明确失败 / 人工处理，不自动当作 false 继续。判断模型调用同样受授权、预算和公平队列约束。
- 触发器保存独立配置与版本：定时的时区 / 规则、文件加入的授权范围、Webhook 的事件契约、任务完成的来源任务与状态过滤。实施时校验运行身份、组织权限、签名与事件来源，进行事件去重、节流、重复触发保护；需要外部地址的凭据仍保存在连接中。长时间等待事件不占执行 worker；本机监听明确设备在线要求，服务端触发需持久调度。本页未注册任何触发器。
- 节点位置、缩放与列表顺序属于视图数据，执行顺序由箭头决定。删除节点同时删除关联连线并标记失效的字段引用；禁止自连接、重复出口与普通回边，触发节点不接受输入箭头。运行前检查不可达节点、未连接出口与字段类型。汇合节点须区分“等待全部并行分支”和“接收实际选择的分支”，不能等待未被选择的分支；第三版仅演示后者。
- 智能体节点使用稳定的资源 ID、版本、定义快照和输入映射，不能用显示名称作为真实关联键。上游节点调整或删除后重新检查依赖，不能默默换一个来源继续执行。
- 沿用现有字符串、数字、布尔值契约；新增文件和图片时使用受控的产物引用类型及声明 MIME，不在普通字符串里混用文件路径、大段 Base64 或密钥。结构化对象 / 数组作为后续明确版本升级，不隐式扩大当前契约。
- 输出须校验类型、必填字段、大小及引用归属；无效输出明确失败或有限次修复，不能把模型叙述直接当有效工具参数。
- 固定版本运行。资源升级、流程编辑不修改已执行记录；下次运行前用户可审阅升级差异。
- 本机任务需要设备在线，首期不承诺关闭应用后继续执行。服务端可恢复任务需要单独接入持久队列、断点和幂等机制；等待授权时释放执行槽位。
- 继续执行已有供应商配额、队列隔离、用户 / 全局预算；不因长任务内部多次调用绕过限额。空闲时允许用户用满可用 worker；有竞争时按用户轮转准入，限制单任务连续占用和重试预算。已运行的外部调用不强制抢占，超时和取消释放槽位。

## 3. 智能体与能力仓库

### 三类资源各自负责什么

| 类型 | 内容 | 不应混淆的边界 |
| --- | --- | --- |
| 工具 | 输入输出契约、执行器类型、允许的动作、超时与副作用声明 | 工具定义不等于可任意运行上传代码 |
| 技能 | 指令、示例、参考资料、适用任务及依赖引用 | 技能文本不获得执行权限，不覆盖用户授权或系统约束 |
| MCP | 连接描述、能力列表、允许的工具、版本、执行位置 | 服务器连接不代表所有远程工具都默认可调用 |

智能体编辑器包含角色指令、输入输出、绑定资源与版本、最大调用次数、运行预算。选择能力时展示可见范围、执行位置、是否需要用户连接、是否会写入或发送数据。工具执行采用注册的执行器，首期优先内置工具与经管理员批准的 HTTP 连接；任意用户脚本运行不作为首期默认能力。

### 创建、分享和执行权限

以下为建议策略，沿用用户已确认的扁平多组织、总管理员任命组织子管理员规则。新的组织 / 共有资源发布审批属于本方案提议，不宣称已经实现。

| 身份 | 私有资源 | 组织资源 | 共有资源 |
| --- | --- | --- | --- |
| 普通用户 | 创建、修改、删除自己的草稿和版本 | 查看所属组织授权资源，提交发布申请 | 查看允许使用的资源，提交发布申请 |
| 组织子管理员 | 管理自己的私有资源 | 审批并维护本组织资源，不能管理其他组织 | 与普通用户一致 |
| 总管理员 | 不自动读取用户本机私有内容或密钥 | 管理组织、成员及资源治理 | 审批、停用和维护共有发布 |

- 草稿归创建者；向组织或共有发布前检查其依赖是否对目标使用者可用。不把私有技能正文、文件或密钥随着智能体共享出去。
- 区分“能看见定义”“能绑定到自己的智能体”“能执行此工具”“能用某个连接”。组织成员身份不能推导出某人的私人 API 凭据使用权。
- 凭据只以单独的连接引用保存。共享智能体、备份、导出及运行记录不得携带明文 Key。服务端连接使用部署者策略，本机连接保留本机加密存储边界。
- 用户退出组织、权限撤销、资源停用后，下一次执行 / 恢复 / 重试前重新授权；历史记录中敏感产物的访问也重新核验。已在执行的外部副作用需明确审计，不能承诺撤销已经发出的操作。
- 发布为不可变版本，更新通过新版本和审批；被引用的版本停用时显示原因，不静默改指向。
- 记录资源创建、版本发布、审批、绑定变更及执行事件；日志保存必要摘要与脱敏参数，不收集连接密钥。

### MCP 接入

先区分本机与服务端连接。服务端首期优先支持受控的远程 HTTP MCP；本机进程型连接仅在桌面运行环境中提供，逐个配置允许的程序与参数，不从共享资源自动执行命令。连接发现、能力刷新和工具调用均按运行者权限检查；限制允许工具、网络目的地、响应大小、超时与调用预算，沿用出站请求保护。

工具与 MCP 输出作为不可信任务数据处理，不能通过返回文本增加权限、切换凭据或指示发送数据。对发送消息、写入外部系统、删除等动作展示具体参数并按已有用户授权范围确认；无需对只读步骤重复弹窗。

## 4. 文档生成：格式决定编辑体验

### 统一入口

用户先选格式，再选空白 / 内置模板 / 参考文件，填写主题或确定内容，插入图片，确认结构后生成。文件成果具有明确的原生格式；Markdown 可作为独立选项或内部草稿，不能把所有任务伪装为 Markdown 再让用户寻找导出菜单。

| 格式 | 模板与编辑方式 | 生成与验收重点 |
| --- | --- | --- |
| DOCX | 章节大纲、标题层级、纸张边距、页眉页脚、表格、图片与分页 | 原生可编辑文档；字体、表格溢出、分页与图片锚点 |
| PPTX | 页面列表、逐页布局、可拖动缩放的文字 / 图片区域、配色 | 文本和图形可编辑；每页布局、字号、溢出和图片位置 |
| XLSX | 工作表、列类型、数据区域、公式、样式、图表与打印区域 | 数据类型、公式依赖、合计、公式注入与原生重算 |
| XLS | 精简的兼容模板和功能提示 | 明确行列 / 格式限制，避免静默丢失 XLSX 专有功能 |

PPT 每个区域选择：直接使用文字、给定主题由模型写作、上传指定图片、描述画面后生成图片。插图生成单独展示连接、费用 / 调用和授权；再次生成某一页不会覆盖其他页已确认的修改。

### 参考内容、模板与素材分开处理

- 内容参考：提取可用内容，标注文件来源和未解析内容。
- 版式模板：解析为格式专用的模板结构 / 占位符，并保留可支持的样式；不能将“已抽取文字”描述为“原模板保真复用”。
- 图片素材：保存明确的资产引用、来源和目标区域；替换或删除素材时检查引用，不依赖易变的数组下标。
- 先支持内置模板及明确占位符的用户模板。任意 DOCX / PPTX / XLSX 的全量布局保真不作为首期承诺；复杂母版、嵌入对象、宏、外链和不支持的图表提前列出限制。
- 不执行上传文件中的宏、外部关系或脚本。限制压缩包展开、图片像素、文件总量与解析时间。用户选择的素材外发给模型前按实际传输内容提示。
- 产物基于格式专用结构生成，保留源设计 JSON、版本和资产引用；支持修改局部后重新导出，避免每次从零生成。
- 原型只有模板选择与布局草案，上传文档只展示名称；预算合计是示例运算，不是 XLS 公式引擎或可下载 Office 文件。

## 5. 图片生成：提示词 + 参考图 + 构图

### 交互建议

左侧：整体提示词、比例、参考图片、风格 / 主体用途、服务端或本机连接。

中间：构图画布，可添加矩形、圆角矩形、椭圆、三角形、文字及后续的自由路径。第三版支持拖动、缩放、旋转和图层调整：顶部圆点旋转，按 Shift 以 15° 吸附，也可输入角度；层级可直接填写，提供上移一层 / 下移一层 / 置顶 / 置底。图层列表从顶层向底层显示，被遮挡对象仍可从列表选中，选中不改变显示优先级。自由路径、位置吸附、撤销 / 重做与构图缩放视图后续补齐。

右侧：选中区域的名称、形状、位置、尺寸、旋转角度、层号、颜色和描述；参考图片绑定与可选的“主体 / 背景 / 文字留白”语义作为后续接入项。

生成前展示最终提示词、实际传递的参考图与构图方式；生成后展示候选图、局部调整、重试和下载。构图草案与生成结果分开保存，生成失败不覆盖用户设计。

### 模型能力必须明确

当前服务端 `ServerImageRequest` 仅接受 `endpoint_id`、`prompt` 和 `consent`，现有接口**没有**参考图片、图生图、蒙版或结构化构图输入。生图调用成功的历史验收不证明这些能力已可用。

实施时为每种供应商建立能力描述与请求适配：

| 能力 | 如何使用画布 | 不支持时如何处理 |
| --- | --- | --- |
| 仅文本生成 | 将位置、比例、色彩和对象描述转成文字提示 | 告知用户仅文字参考，用户主动选择继续；不宣称上传图已送达 |
| 参考图 / 图生图 | 发送原始参考图、画布栅格预览与文字说明中供应商支持的部分 | 不将参考图悄悄丢弃，也不自动切换为不同效果的方式 |
| 蒙版 / 布局控制 | 将区域转换为该接口支持的蒙版或布局参数 | 明确控制强度和限制，不能保证几何完全一致 |

画布以百分比坐标保存未旋转的对象框，旋转绕对象中心顺时针计角（0–359°）；旋转后超出画布的部分裁切。层号从 1 开始，数值越大越靠前，重排时保持唯一连续顺序；复制保留旋转 / 描述并放到顶层，删除后重排层号。`ImageDesign` 和导出说明同时包含 `rotation` 与 `layer`，不能仅改变 CSS 预览而丢失模型输入约束。旋转后的缩放在对象局部坐标处理。实施时可按目标分辨率栅格化预览，但不能保证供应商精确遵从角度和叠放。图片输入做格式、字节、像素与数量限制；使用现有本机 / 服务端连接隔离策略。中文文字的准确渲染不能依赖生图保证；后续可提供生成底图后叠加可编辑文字的方式。

## 6. 迁移与数据结构

以下是待实施的逻辑对象，不是已部署 API：

- `LongTaskDefinition`：版本、流程节点 / 连线（含源出口和目标入口）、智能体版本引用、字段映射、判断契约、触发配置、预算。节点位置 / 缩放 / 列表顺序作为视图状态保存；演示的判断结果不作为真实执行结论。
- `CapabilityResource`：类型、所有者、可见范围 / 组织、发布状态、不可变版本、输入输出、执行边界与连接需求。
- `AgentDefinition` 扩展：保留现有角色与字段，新增能力引用、版本与调用限制；旧智能体没有能力字段时默认为空。
- `DocumentDesign`：目标格式、格式专用设计、模板引用、材料和图片引用、用户确认内容与产物版本。
- `ImageDesign`：整体提示词、画布比例、对象坐标 / 尺寸 / 中心旋转角 / 显示层号 / 描述、参考图用途、选定能力模式。旧设计默认旋转 0°、层级按旧对象顺序迁移。
- `RunRecord`：执行者、使用资源版本、权限决策摘要、状态、节点结果、产物、脱敏错误与耗时。

升级现有本机加密草稿、备份和共享校验器时保留旧格式读取与明确的版本转换。用户草稿迁移先备份，不删除旧多步骤 / PPT 历史记录。组织资源和工作流沿用已实现的组织关系；服务端只接受明确允许的字段，引用不可绕过所有者与组织隔离。

## 7. 建议实施批次与完成标准

1. **入口与兼容迁移**：合并“长任务”和“文档生成”，保留旧记录；两种流程视图切换不丢数据；PPT 设计入口合并后功能不退化。
2. **能力仓库与智能体**：私有 / 组织 / 共有的创建、版本、审批、绑定和运行授权；组织退出、资源撤销、跨租户引用、类型错误及旧备份回归通过。
3. **按格式生成**：DOCX / PPTX / XLSX 结构设计与模板、插图、局部重生成，XLS 兼容路径；验证文件可打开、内容正确、版式和公式可用。Office 原生渲染验收单独记录，不用网页预览替代。
4. **图片生成与画布**：独立入口、参考图、图形说明、模型能力适配；真实连接验证支持和拒绝路径、取消、额度与图像限制。先使用合成素材验收。
5. **联合验收**：长任务调用智能体生成文档与图片；跨组织权限、重试幂等、并发公平性、暗色和移动布局、断开 / 恢复与旧任务兼容。区分浏览器模拟、真实供应商、原生文件、构建和线上部署证据。

本方案不以目标部署准备为开发前置条件；但跨平台文件渲染、实际供应商能力及部署等价压测的验收结论须有对应环境证据。发布、推送与部署不属于本轮原型交付。

## 8. 样例体验路线

1. “长任务”中拖动节点；从节点出口拖向另一节点入口连线。添加智能体、函数 / 智能体判断或触发事件，选择节点配置；点击箭头可删除。切换步骤视图仍可见分支去向。选中“证据是否充分”，切换演示结果再运行，检查两条路径；切换触发器只模拟事件到达。
2. “文档生成”中切换格式；进入 PPTX，选择页面、添加区域，拖动缩放并填写内容主题。
3. “图片生成”中添加形状、拖动缩放、拖动顶部圆点旋转或输入角度；填写层号、上下移动图层或置顶 / 置底。修改描述、上传参考图；点击“查看构图说明”或导出需求 JSON，核对旋转和层号。
4. “智能体仓库”中添加工具、技能、MCP 引用；到“资源仓库”筛选或创建资源草稿。
5. 左侧栏底部切换深浅色；窄屏可用顶部主题按钮，左上角按钮展开侧栏。
6. 点击顶部“文档”查看阅读入口示意，再返回“任务”，检查流程草稿仍保留。顶部“对话 / 模型”只展示已有入口关系，不连接实际会话或模型设置。

完整后端权限、审批、真实解析和执行尚未接入。样例允许跨范围引用以展示编辑方式；正式实现必须按第 3 节检查依赖可见性和执行权限。
