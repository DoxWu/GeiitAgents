# 模型列表与能力状态

2026-09-29：已实现并完成本机隔离验证；同日后续流式批次补齐真实 WebView2 原生目录读取验证。用于工作台聊天模型，不修改本地知识库向量配置，也不下载模型。

## 使用流程

1. 选择本机直连或个人云端临时转发，填写 Base URL 和所需 API Key。可以先获取列表，再填写连接名称和模型名称。
2. 点击“获取模型列表”。没有自动请求、自动选择或自动保存；选择列表项只填入模型名称，仍可手动修改。
3. 列表为空、不支持 `/models`、权限不足、网络失败或浏览器未允许跨域时，仍可手填并保存连接。
4. 保存后“测试连接”发送 `Reply OK.` 短消息，可能按服务商规则计费。成功后显示“文本调用：本次测试已验证”。失败不自动切换模型。

模型名称、端点、密钥或输出限制变化会使本次文本验证失效。证据只在当前表单生命周期内有效，不作为长期可用性保证。改端点/密钥、切换连接、退出页面、锁库或切换账号时，旧列表请求被取消，迟到结果不会回填。

列表和能力状态仅驻留内存，不写入本机加密库或服务端数据库。账号云端区域复用已有权限检查，只显示获准使用的服务端配置；不会使用服务端密钥读取供应商的全部模型目录。

## 能力边界

| 信息 | 当前证据与行为 |
| --- | --- |
| 列表可见 | 供应商 `/models` 返回了有效 ID；不证明该模型能聊天，列表也可能含向量模型 |
| 文本调用已验证 | 当前已保存连接收到非空文本响应；不要求回复严格等于 OK |
| 工具调用、图片输入、上下文长度、最大输出长度 | 均为未知；不根据模型名或供应商任意 metadata 推断 |
| 最大输出 Token | 可选，未配置时继续不发送 `max_tokens`；不会用列表信息自动填入 |
| 本地向量模型 | 独立管理，默认按需 `Xenova/multilingual-e5-small`；此功能不触碰其模型、文档或索引 |

没有工具调用协议、多模态内容、专有供应商协议或通用能力探测器。后续需要明确的适配契约和独立调用验证，不能将当前“未知”当作支持。

## 接口

| 路径 | 行为 |
| --- | --- |
| Web 本机 | `GET {baseUrl}/models`；仅 localhost / 127.0.0.1 / [::1]，HTTP 或 HTTPS。密钥可选，使用 Authorization Bearer；omit cookies、no-store、拒绝重定向。浏览器需服务允许跨域 |
| Tauri 本机 | `list_local_models({requestId, baseUrl, apiKey})`；Rust 回环请求，localhost 固定为 127.0.0.1，不用系统代理，拒绝重定向；取消复用 `cancel_local_model` |
| 个人云端 | `POST /api/v1/private-models/models`，需活跃账号，单独每分钟 20 次限流。仅 body `{ "base_url": "https://models.example/v1" }`，Key 仅 `X-Model-Api-Key` 头传入 |
| 账号云端 | 原有 `GET /api/v1/private-models/account`，无新增目录接口或客户端指定服务端模型的权限 |

个人云端返回：

```json
{
  "models": [{ "id": "provider-model-id" }],
  "truncated": false
}
```

服务端请求上游 `GET /models`，没有聊天消息、输出 Token 或 Key body 字段。请求 schema 禁止额外字段；非法输入统一报错，避免回显输入。成功和路由内错误响应带 `Cache-Control: no-store`。认证/全局限流错误沿用现有中间件。

只接受 `{data: [{id: string}, ...]}` 兼容格式；去重、最多展示 500 个、ID 最长 200 字符，拒绝空/前后空白/控制字符。无效条目被跳过；达到数量上限、跳过无效条目或上游 `has_more: true` 时标记 truncated。供应商其他字段全部舍弃，不自动跟随分页链接；没有通用目录分页适配。

## 安全、取消与限制

- 保存与获取列表共用密钥端点绑定检查：复用已保存密钥时，修改地址必须重新填写或明确清除密钥。读取草稿列表不会把新密钥写入存储；保存仍使用原有本机加密库。
- 云端只允许 HTTPS 公网 443；DNS 结果只要混入私网/保留地址即拒绝。一次解析后使用固定 IP，保留 TLS 主机名和 Host；不使用环境代理，不跟随重定向。
- 上游列表响应最多 1 MiB，服务端 HTTP 操作总超时 20 秒（DNS 另有 5 秒上限）；原生 HTTP 20 秒，客户端列表/测试 25 秒取消。共享最多 3 个工作台模型请求槽位，原生桥接另有 4 个并发上限。
- 上游错误 body 不转发，传输异常不携带供应商详情。反向代理/监控不得记录密钥头；这仍需未来部署核验，不能仅凭应用代码承诺基础设施无日志。
- 页面取消会停止客户端等待，锁库/账号变化阻止回填；原生桥接发送取消命令。服务端普通 HTTP handler 不保证在客户端断开时立即终止上游 GET，上游最多继续至操作结束或超时；不自动重试、排队或保留密钥用于后续任务。
- 账号云端配置可用不代表当前供应商已在线，不会自动发计费请求进行探测。
- 模型列表初始批次未包含原生聊天流式；同日后续已补齐 Tauri 工作台聊天增量显示和真实 WebView2 目录/聊天验证，见 [原生聊天流式](NATIVE_MODEL_STREAMING.md)。未传增量回调的文档任务/本地库回答仍完整返回。
