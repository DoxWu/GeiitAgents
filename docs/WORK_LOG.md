## 已确认决策

新增版本管理决策（2026-09-20）：在独立 `develop/geiit-agents` 分支保存本地提交；旧 `main` 基线保留。新远程 `agents` 指向 `https://github.com/DoxWu/GeiitAgents.git`，设置为默认推送目标，旧 `origin` 保留溯源。用户要求功能较完善后再推送，当前不推送/发布、不强制覆盖历史。当前批次继续实现本地库备份与恢复，并补开发客户端数据隔离。

1. 将现有 Web 知识库扩展为桌面办公助手，保留 Web 与服务端。Windows/Tauri 首版已有验证实现，其他平台尚未验证。
2. 多个对话隔离不同任务；后续工具任务需要独立持久状态，不能只依赖当前聊天请求。
3. 用户 API Key 本机加密保存，云端仅在当前模型请求内临时使用。日志、代理和监控还要满足不记录凭据的部署要求。
4. 最大输出 Token 可选，默认不配置、不发送 `max_tokens`。
5. 本地密钥库解锁口令允许至少 4 位。这里不是将厂商 API Key 截成 4 位，也不改变服务端账户密码规则。
6. 没有个人模型连接时，有权限的已登录账户可用服务端模型；已有个人连接失败不能静默切换到其他云端模型。
7. 线上部署平台是 Sealos；用户尚未创建异地备份库。恢复结构与恢复历史业务数据是两件事。
8. 客户端本地向量模型**仅用于用户本地知识库**，云端知识库继续使用现有服务端模型。模型配置、文档、索引和检索入口分别管理。
9. 本地库默认模型：原模型 `intfloat/multilingual-e5-small`，ONNX 仓库 `Xenova/multilingual-e5-small`；用户可单独配置其他兼容向量模型。BGE 不再是默认候选。
10. 默认不下载/加载本地知识库模型；只有终端用户主动明确启用本地知识库，才安装相应资源。完整本地问答还需选择本地生成模型，使用云端生成模型须明确处理片段出站。
11. 每次完成工作都更新本文件；已写入根目录 `AGENTS.md`，便于后续工作继续执行。
12. 2026-09-20：先进行应用改造，完善备份与恢复接口；暂停当前部署排查/供应商选择，后续视情况制定新方案。已有 Sealos/PVC/备份资源待办仅作历史及未来部署参考，不阻塞开发。

## 注意事项与已发现的坑

| 问题 | 实际影响 / 处理原则 |
| --- | --- |
| 自动迁移不是数据恢复 | 没有备份不能找回账号和历史文档；接口拒绝覆盖已有数据，实际持久化问题留待后续部署阶段核实 |
| 同平台监控也会一起停 | Sealos 整体故障需外部监控；外部监控自身也需要独立可用性观察 |
| 备份环境限制 | 托管库可能没有 CREATEDB/pgvector；pg_dump 版本不能低于源库；密钥丢失无法还原 |
| PostgreSQL dump 不含文件字节 | uploads/对象存储、Redis 与配置需各自备份；定时 dump 不是主从切换/PITR |
| 空库判断要保守 | 只恢复真正空库；部分表损坏不可自动清空覆盖；错误密钥/过期备份必须拒绝 |
| 默认本地模型体积 | E5 单个 INT8 ONNX 约 118 MB，不含运行时/tokenizer；不是此前 BGE 的 24 MB，不应默认随安装包捆绑 |
| 向量空间不兼容 | 同维度也不能混用；模型、前缀、pooling 或切块规则变化必须重建相应本地索引 |
| 名称容易混淆 | 客户端向量模型、聊天模型和服务端 LOCAL_EMBEDDING 是三个独立概念，不复用同一开关 |
| 现有服务端兜底 | 历史 BGE 兜底与云端向量空间兼容性需要另行审查，本轮未调整或声称已解决 |
| 本地检索不等于本地回答 | 云端聊天模型会收到用于回答的片段；需要用户明确选择，不默默上传 |
| 模型兼容性 | 不能只填模型名；ONNX 架构/量化/tokenizer/pooling 均需适配，不执行任意下载脚本 |
| 四位解锁口令 | 只是本地解锁最低长度，不是 API Key 长度；加密不等于能抵御弱口令离线猜测；口令丢失当前不可恢复 |
| 客户端关闭或锁定 | 云端没有用户 Key 可继续调用；后续任务需 waiting_device，不能伪称后台持续运行 |
| 客户端缓存 | 会话密文在 localStorage；本地库为独立 IndexedDB + 模型 Cache Storage，当前文档未加密，同一 origin/客户端数据目录的账号共享；不同 origin 不共享 |
| 前端环境与桌面跨域 | 桌面构建需正确 VITE_API_BASE_URL，后端 CORS 需桌面 origin；切勿把 Key 放 VITE_* |
| Windows 测试环境 | Python DEBUG 环境曾为非法值 release；测试设置进程级 DEBUG=true；pytest 默认临时目录权限失败需工作区 basetemp |
| 源码/二进制对应 | 2026-09-20 已重建含本地库的 Windows 验证包，仍是未签名 0.1.0 开发包；未发布，不能将本地包视为线上更新 |
| HTTP 恢复与 CLI 目标不同 | HTTP 使用 RESTORE_TARGET_DATABASE_URL 的独立空库；直接 CLI restore 使用 DATABASE_URL，均不会清空已有库 |
| 执行中断的不确定结果 | 恢复可能成功但状态没写回；任务标记 interrupted，不能自动重放，先核查目标 |
| 手动任务保留快照 | 排队/执行中引用的快照暂缓清理，保留数量可能暂时大于设置值 |
| 幂等范围 | 同一数据源 + 同一个 request_id 才去重；新 ID 是新任务，页面重载后先查列表 |
