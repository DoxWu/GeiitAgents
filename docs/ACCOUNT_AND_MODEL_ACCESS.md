# 账号服务器与无需登录的模型访问

2026-10-09，dev.67。

登录、注册和密码页面可通过“关闭 / 返回工作台（无需登录）”退出。无需账号也能创建或解锁本机密钥库，使用本机模型与自购 OpenAI-compatible API。

## 账号服务器

- 桌面端默认 `https://api.geiit.online/api/v1`。页面显示实际应用的账号请求目的地；用户填写组织或个人服务器后点击“使用此地址”。编辑尚未应用的地址会明确提示；“恢复默认”切回默认服务。
- 根地址自动补 `/api/v1`；反向代理前缀保留。Web 自托管继续支持构建参数 `VITE_API_BASE_URL`，包括同源 `/api/v1`；界面展示解析后的完整地址。
- 使用 HTTPS；本机 localhost / 127.0.0.1 / [::1] 开发地址允许 HTTP。地址拒绝内嵌凭据、查询参数和片段。
- 切换服务器清除旧账号状态、Token 和云端文档状态，中止账号请求；迟到的登录、刷新和账号响应不会写回新会话。Token 绑定账号服务器，登录不附带旧 Bearer；fetch 拒绝重定向、不附带 Cookie。未绑定旧桌面会话需重新登录，已有本机模型连接与加密数据继续保留。
- 普通账号 API、刷新、账号模型/转发请求、通知 WebSocket 和提醒草稿的账号归属都遵循所选服务器。
- 自托管服务器仍须配置浏览器/桌面来源的 CORS 和 WebSocket 支持；选择地址不代表已部署或已验证该服务。

## 模型连接

| 调用方式 | 登录要求 | 请求目的地 |
| --- | --- | --- |
| 自购 API 直连（新连接默认） | 无需账号，API Key 必填 | 用户填写的 HTTPS 模型地址，443 端口 |
| 本机直连 | 无需账号，API Key 可选 | localhost / 127.0.0.1 / [::1] 模型服务 |
| 云端临时转发 | 需要所选账号服务器的登录状态 | 所选账号服务器临时转发到模型服务 |
| 账号云端模型 | 需要账号及权限 | 所选账号服务器管理的获准模型 |

直连 API Key 和连接配置继续加密保存在本机密钥库；聊天、模型目录、文本/工具/视觉测试、办公任务、工作流及本地知识库回答使用所选连接。桌面端通过受限 Rust HTTP 传输，拒绝重定向且不使用 Cookie；网页直连需模型服务允许跨域。仅支持当前 OpenAI-compatible 协议，不保证每个供应商的专有格式均兼容。

自购 API 属于云端模型：发送本机图片、任务材料、工具结果和本地知识库片段仍需要原有逐次明确授权。账号退出只中止账号模型与转发请求；锁定密钥库仍中止全部模型请求。模型目录与本地向量模型配置、文档及索引分别管理，不会自动下载向量模型。

“获取模型列表”旁显示等待状态、不确定进度条和“取消获取”；20 秒超时后明确提示，失败可手填模型名称。取消、编辑接口、切换账号、卸载组件后的迟到列表不能回填。
