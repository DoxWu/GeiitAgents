# 生成图片下载验收（2026-11-02）

## 改动与调查边界

用户报告点击生成图片的下载链接没有反应。原按钮是直接指向完整 Base64 data URL 的链接，且没有点击反馈。本轮改为校验图片后创建带实际 MIME 的 Blob，通过临时文件链接启动下载；按内容类型纠正扩展名、替换文件名中的路径/控制字符，随后释放临时链接。工作室按钮显示下载已开始或失败重试提示，仍服从锁库及任务切换的禁用状态。提示“已开始”不等同于确认用户已经完成保存。

本次在独立 WebView2 profile 中用 dev.76 对照测试，旧链接也能成功保存 3,147,780 字节 PNG。因此没有复现用户现场的无响应，不能认定大 data URL 是该次问题的唯一根因。新实现避免直接导航大 data URL，并与现有文档下载的 Blob 方式保持一致。实际运行的用户应用版本只读确认是 dev.76；没有读取其密钥库、停止进程或替用户升级。
