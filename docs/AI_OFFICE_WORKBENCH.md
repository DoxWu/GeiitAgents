# AI 办公与网页设计

工作台的「任务」页提供文档生成和网页设计。模型请求使用当前选定的本机、自购 API 或账号模型；云端连接每次任务都需要单独授权。任务输入、运行记录和成果保存在本机加密库中。下载的文件是未加密副本，分享前应检查内容。

## 文档生成

在「文档生成」中填写标题和要求，可粘贴文本或载入 UTF-8 Markdown/TXT 文件。单个参考文件不超过 2 MiB，文本上限 100,000 字符。已解析的参考文本可保存到本机资料库，最多 20 份；资料库随本机密钥库加密，可在任务页或 Markdown 预览页再次载入，无需重新选择源文件。资料库不自动向模型发送材料，只有实际启动云端任务并勾选授权后，文本才会随该次请求发送。

模型先生成可编辑的 Markdown 成果，然后可从成果区导出：

- DOCX：可选择版式、纸张、字体、字号、行距和页边距，并设置页眉、页码和自动目录；目录字段由 Word 打开时更新。Markdown 中单独一行 `<!-- pagebreak -->` 可请求分页。表格限制为最多 8 列、2000 个单元格，并按页面可用宽度布局。链接图片不会联网下载或嵌入。
- PPTX：根据 Markdown 标题和段落拆分演示页，最多 50 页；支持编辑型段落、列表和表格，长内容会分页。它不保留 Word/Markdown 的原始版面、图片或动画；导出后请在 PowerPoint 中复核页数和溢出。
- XLSX：导出 Markdown 中第一张表格，最多 50 行、12 列；文本保持为文本，安全的数值内容可写为数字单元格，并带表头、列宽、筛选等基础样式。不计算公式。没有合规表格时导出会提示失败。
- XLS：可导出 Excel 97–2003 兼容的 BIFF8 二进制工作簿；同样只包含第一张 Markdown 表格，最多 50 行、12 列，保留文本、列宽及安全数值单元格。长中文使用共享字符串保存，公式样式文本不执行。当前写入器不输出表头配色、冻结或自动筛选；需要这些功能时使用 XLSX。
- HTML：导出静态 HTML 阅读版。

这些导出是本机格式转换，不会再次调用模型。Office 导出不等于对任意源文件进行保真转换；复杂版式、公式计算、图表、图片及真实模板均需在目标 Office 软件中复核。Word 中的目录依赖 Office 更新字段；PDF/LibreOffice 多环境组合尚未完整验收。XLS 为旧式 BIFF8 格式，兼容范围较窄；新项目优先使用 XLSX。

## 网页设计

在「网页设计」中设置名称、需求、页面排版、主色/副色、页面底色、文字、内容底色和按钮颜色；可选择滚动触发、滚动联动、视差滚动、吸顶、滚动吸附和横向滚动，并切换动画示例。另可填写示例文字并附加最多 3 张 PNG/JPEG/WebP 图片，每张最多 1.5 MiB。

生成任务会把设计配置、文字样例和图片作为一次模型输入。云端模型需要逐次授权。图片先保存在本机加密库，生成时才随所选模型请求发送；浏览器预览使用本机素材。

应用只把模型返回的完整 HTML 代码块作为网页预览，成果以独立 HTML 文件下载。预览通过独立静态入口和响应 CSP 加载，允许生成页面的内联动画脚本；主应用仍禁止内联脚本。预览内容位于关闭同源访问和表单的沙箱 iframe，独立 CSP 禁止网络连接。预览脚本不能读取应用页面或应用存储，桌面桥接在子框架中拒绝命令且不安装 invoke key；下载页面也保留禁止网络连接的 CSP。图片占位符展开后的页面大小设有上限。模型生成的页面代码仍需人工检查，尤其是在把下载文件部署到其他主机之前。完整本机证据见 [工作台原生验收](NATIVE_WORKBENCH_ACCEPTANCE_2026-10-22.md)。

## 数据边界

本机资料库、任务记录和成果由本机密钥库加密保护。模型输入按每次任务的连接方式和授权范围发送；本机模型是否真正离线取决于它自身的部署。浏览器本地 Markdown 预览不上传文件，只有明确载入为生成任务输入并执行云端任务后才会发送相应文本。
