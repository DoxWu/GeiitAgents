# AI 办公与网页设计

工作台的「任务」页提供文档生成、图表工具、长任务、网页设计、图片生成、智能体仓库和资源仓库七个入口。PPT 逐页设计位于文档生成内；自主多步骤任务与可视化工作流位于长任务内。切换已访问的页签会保留编辑状态。模型请求使用当前选定的本机、自购 API 或账号模型；云端连接每次任务都需要单独授权。任务输入、运行记录和成果保存在本机加密库中。下载的文件是未加密副本，分享前应检查内容。

## 文档生成

左侧任务列表顶部固定「新建文档任务」，历史记录在下方单独滚动。新建界面只显示格式、模板和输入；选择历史任务后，只显示该任务的状态、执行记录和成果。通过「复用输入新建」载入旧任务的标题、要求、材料和格式，再发起独立任务；新建按钮会清空当前输入。任务完成不会把用户从已切换的其他任务或新建界面拉走。

在「文档生成」中先选择文件类型和内置内容模板，再填写标题和要求。可粘贴文本或读取参考文件；PDF/DOCX/PPTX 等提取文本，XLSX 只读取首个可见工作表的受限数据，不保真复用原文件版式。已解析的参考文本可保存到本机资料库，最多 20 份、每份 100,000 字符；资料库随本机密钥库加密，可在任务页或 Markdown 预览页再次载入，无需重新选择源文件。资料库不自动向模型发送材料，只有实际启动云端任务并勾选授权后，文本才会随该次请求发送。

开始任务前先选择目标文件类型（默认 DOCX）；模型生成的内容仍以可编辑 Markdown 版本保存在任务记录中，成果区按所选格式生成文件：

- DOCX：可选择版式、纸张、字体、字号、行距和页边距，并设置页眉、页码和自动目录；目录字段由 Word 打开时更新。Markdown 中单独一行 `<!-- pagebreak -->` 可请求分页。表格限制为最多 8 列、2000 个单元格，并按页面可用宽度布局。链接图片不会联网下载或嵌入。
- PPTX：文档生成任务可将 Markdown 内容整理成演示文稿，最多 50 页；支持编辑型段落、列表和表格，长内容会分页。若要控制每页排版、颜色和图片，请使用下方的「PPT 设计」。
- XLSX：导出 Markdown 中第一张表格，最多 50 行、12 列；文本保持为文本，安全的数值内容可写为数字单元格，并带表头、列宽、筛选等基础样式。不计算公式。没有合规表格时导出会提示失败。
- XLS：可导出 Excel 97–2003 兼容的 BIFF8 二进制工作簿；同样只包含第一张 Markdown 表格，最多 50 行、12 列，保留文本、列宽及安全数值单元格。长中文使用共享字符串保存，公式样式文本不执行。当前写入器不输出表头配色、冻结或自动筛选；需要这些功能时使用 XLSX。
- HTML：导出静态 HTML 阅读版。

这些导出是本机格式转换，不会再次调用模型。Office 导出不等于对任意源文件进行保真转换；复杂版式、公式计算、图表、图片及真实模板均需在目标 Office 软件中复核。Word 中的目录依赖 Office 更新字段；PDF/LibreOffice 多环境组合尚未完整验收。XLS 为旧式 BIFF8 格式，兼容范围较窄；新项目优先使用 XLSX。

## PPT 逐页设计

在「文档生成」选择 PPTX 后，创建并重排最多 50 页，每页可选择标题页、要点列表、文字与图片、重点引语、图片页或自定义版式。自定义区域支持拖动、缩放、旋转、层号、颜色和逐区域说明；预设页与自定义页可以混用。用户可以直接填写正文，也可以填写本页或文字区域的内容主题后由模型生成具体文字。主题可分别设置主色、副色、页面底色、内容底色和文字颜色，并在页面预览中检查结果。设计草稿保存在本机加密库中；导出保留可编辑文字与基础图形。

PPT 与其他文档共用左侧任务列表。历史设计通过「继续编辑与导出 PPTX」恢复，不在新建设计中混入历史记录下拉框；旧版直接生成的 PPTX 内容也可复用为逐页设计。

每页可上传一张 PNG/JPEG/WebP 图片，也可从加密保存的本机模型连接或部署者通过 `.env` 配置的服务端 OpenAI-compatible 图片接口生成。服务端接口只公开已完整配置的模型名称，不向客户端返回服务端 Key；选择服务端模型时，每次生成都要明确授权发送描述，服务端 API Key 不进入本机密钥库。全稿最多 50 张、图片总量不超过 4 MiB；视觉模型请求最多发送前 3 张图片。云端文字和生图请求分别要求本次授权。内容生成须按既有页面顺序返回，不会替用户增加或合并页面；生成后版式、颜色和图片保持不变。导出的 PPTX 使用可编辑文字与基础形状，不承诺复杂版式或图片裁切与 PowerPoint 完全一致，使用前请在 PowerPoint 中复核。

## 图表工具

可手动输入 CSV，或导入 CSV/XLSX，然后检查数据并预览。也可展开「从图表图片生成」，上传 PNG/JPEG/WebP（单图最多1.5 MiB），选择支持图片理解的模型，并补充需要保留的系列、单位或目标图表类型。云端模型每次调用需单独授权发送图片和补充要求；本机模型使用已有本机连接。

识别结果先经过与手动 CSV 相同的字段和数值检查，通过后载入可编辑草稿与未保存预览。支持柱状图、水平条形图、折线图、饼图和散点图，最多50条数据、12列和6个数值系列；饼图仅单系列。可以继续修改数据、标题、单位、系列和类型，再点击「保存图表任务」。图片、识别结果不会直接自动保存；保存后的图表支持 SVG、PNG 和 XLSX 数据下载。

模型可能从柱高或曲线估读数值，识别说明会随草稿显示；请对照原图复核。结构与数值格式检查不证明识别准确性，原图和估读说明不会自动存入图表任务。已生成成果的「图表视觉审阅」是独立入口，只评估可见布局，不能代替数据识别或业务核验。

## 智能体仓库

在「智能体仓库」定义名称、用途、系统指令以及有类型的输入/输出字段（文字、数字或布尔值），保存到本机加密的私有仓库。登录用户可以发布到全站共有仓库，或发布到自己已加入的组织；用户只会看到自己有权访问的全站/组织定义。全站版本由发布者管理，组织子管理员可管理本组织版本；其他使用者复制后拥有自己的私有副本。共有内容只包含指令和字段契约，不包含模型密钥。

多步骤任务和可视化工作流可以加入仓库智能体。步骤输入必须映射到参考材料、CSV、前置文本、固定值或直接相连的上游智能体输出；上游与输入字段的类型必须一致，模型输出只能包含已定义字段并通过运行时校验。已保存流程包含智能体定义快照，后续共有版本变更不会静默改写既有任务。云端运行前会逐次请求授权；使用者仍需检查共享指令及输出。

## 长任务与函数

「长任务」包含可视化流程和自主多步骤任务。流程中可加入智能体、调用函数、函数/智能体判断、触发节点和已有基础工具；节点可拖动，从出口点击或拖动到入口建立箭头，选中箭头可删除。列表与画布使用相同连接关系；执行顺序由连线决定。输入输出只接受声明的文字、有限数字和布尔值，运行前检查字段类型和直接上游关系。

函数可以手写、从工具仓库选择，或让模型根据用途和字段契约编写；检查代码、隔离试运行并确认后才能执行。每次运行使用新的 QuickJS Web Worker，限制为 1 秒计算、16 MiB 内存、512 KiB 栈及 10 秒初始化/总看门狗；不提供网络、文件、DOM、Node 或桌面宿主接口。只支持同步纯 JavaScript 函数体；代码或契约变化、从文件导入后需重新确认。

定时与应用事件触发仅在客户端开启、密钥库解锁时工作；支持已保存参考资料加入、独立文档完成和待办完成等应用事件。触发器使用保存的输入快照，云端/MCP 调用等待本次授权，锁库或关机不会自动重放。尚不支持 Webhook 或服务端离线持续调度。含远程副作用的未完成步骤不会自动续跑，先核验外部执行结果。

## 资源仓库

用户可添加工具、技能和 MCP，并为智能体绑定固定版本。本机私有资源加密保存；发布组织或共有能力需要相应管理员审批，停用或组织成员资格撤销后，执行时再次检查权限与版本。技能提供指令，不获得额外执行权限；工具首期为隔离函数。

MCP 首期支持无凭据的公网 HTTPS Streamable HTTP 接口及一个明确指定的工具，接受 JSON/SSE 响应；不支持本机 stdio、私人 API Key 或自动发现全部工具。调用受输入输出契约、出站地址检查、时间/体积/并发预算约束。MCP 可能操作外部系统，运行前核对绑定的服务和输入映射；共享版本不携带连接密钥。

## 图片生成

「图片生成」提供整体提示词、最多两张参考图和构图画布。可添加图形、文字或图片区域，拖动、缩放、绕中心旋转，并设置层号、颜色和每个区域的说明；选中对象不会自动改变叠放顺序。草稿和生成结果加密保存，可使用已有服务端或本机连接生成并下载图片。

当前生图连接使用文字生成接口；构图会转换为文字提示，参考图可先由视觉模型理解并整理描述。界面说明实际发送内容，视觉分析与生图分别授权；参考图与画布并非直接送入图生图或蒙版接口，不能保证像素级位置、旋转和层级还原。图生图、蒙版及任意参考模板保真复用仍需后续供应商适配。

## 网页设计

在「网页设计」中可选择杂志纵向、左右分栏、卡片网格或自定义画布作为排版起点。画布支持文本、图片、表格、动画、按钮、多页签、表单、导航栏、悬浮窗、悬浮按钮和链接；用户可选择直角、圆角、胶囊、圆形或虚线边框，拖动画布上的手柄调整位置，拖动右下角调整尺寸，也可用位置和尺寸滑杆精细调整。每个组件可单独编辑名称、展示内容、设计说明、形状、前景色和底色；图片组件可绑定已上传的素材。设计说明会和组件坐标、尺寸、颜色及内容一起放入本次生成请求，作为模型生成网页的参考。

页面主题支持主色/副色、页面底色、文字、内容底色和按钮颜色；滚动效果支持滚动触发、滚动联动、视差滚动、吸顶、滚动吸附和横向滚动，并可切换动画示例。另可填写页面级示例文字并附加最多 3 张 PNG/JPEG/WebP 图片，每张最多 1.5 MiB。

生成任务会把设计配置、组件说明、文字样例和所选图片作为一次模型输入。云端模型需要逐次授权。图片先保存在本机加密库，生成时才随所选模型请求发送；浏览器预览使用本机素材。旧网页设计任务没有组件布局数据时，仍可载入原页面、配色、动效和图片设置，并使用默认组件画布。

应用只把模型返回的完整 HTML 代码块作为网页预览，成果以独立 HTML 文件下载。预览通过独立静态入口和响应 CSP 加载，允许生成页面的内联动画脚本；主应用仍禁止内联脚本。预览内容位于关闭同源访问和表单的沙箱 iframe，独立 CSP 禁止网络连接。预览脚本不能读取应用页面或应用存储，桌面桥接在子框架中拒绝命令且不安装 invoke key；下载页面也保留禁止网络连接的 CSP。图片占位符展开后的页面大小设有上限。模型生成的页面代码仍需人工检查，尤其是在把下载文件部署到其他主机之前。完整本机证据见 [工作台原生验收](NATIVE_WORKBENCH_ACCEPTANCE_2026-10-22.md)。

## 组织

总管理员可建立组织、在注册申请审核时指定组织，或直接调整成员及任命组织子管理员。用户也可以提交加入/退出申请，由组织子管理员审核；成员资格用于访问对应组织的知识库、智能体和工作流模板。移出组织后会失去这些资源的访问权。组织为扁平结构，用户可同时加入多个组织；组织共享内容依赖部署者应用数据库迁移。

## 数据边界

本机资料库、任务记录和成果由本机密钥库加密保护。模型输入按每次任务的连接方式和授权范围发送；本机模型是否真正离线取决于它自身的部署。浏览器本地 Markdown 预览不上传文件，只有明确载入为生成任务输入并执行云端任务后才会发送相应文本。
