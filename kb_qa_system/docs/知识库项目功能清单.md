## 1. 认证与用户管理

### 1.1 注册申请

| 项目 | 说明 |
|------|------|
| **功能名称** | 用户注册申请（前后端整合） |
| **功能作用** | 用户通过邮箱申请注册账号，需输入两次邮箱地址（一致性校验防输入错误），提交后由管理员审批 |
| **后端实现** | API 路由：`app/api/routes/registration.py`；邮件服务：`app/services/email_service.py`（Resend SMTP）；数据模型：`app/models/registration.py` |
| **前端实现** | 页面：`src/pages/RegisterApplyPage.tsx`；API 封装：`src/api/auth.ts`；表单校验：两次邮箱一致性校验 |
| **技术栈** | FastAPI + Pydantic + Resend SMTP + React + Zustand |
| **核心逻辑** | 1. 前端两次邮箱输入一致性校验<br>2. 后端检查邮箱是否已注册<br>3. 创建注册申请记录（status=pending）<br>4. 发送通知邮件给管理员<br>5. 管理员审批后发送密码设置链接 |
| **输入输出** | **输入**：`{email, email_confirm, reason}`<br>**输出**：`{message: "申请已提交"}` |
| **关键配置** | `EMAIL_ENABLED`、`SMTP_HOST`、`SMTP_PORT`、`ADMIN_NOTIFY_EMAIL`、`PASSWORD_TOKEN_EXPIRE_HOURS=24` |

### 1.2 密码设置

| 项目 | 说明 |
|------|------|
| **功能名称** | 密码设置（Token 链接） |
| **功能作用** | 管理员审批注册申请后，系统发送含 token 的密码设置链接，用户通过链接设置密码 |
| **后端实现** | 路由：`registration.py` + `email_service.py`；Token 生成：`secrets.token_urlsafe(32)`（256 位熵）；Token 存储：SHA-256 哈希后存数据库 |
| **前端实现** | 页面：`src/pages/SetPasswordPage.tsx`；路由：`/set-password/:token` |
| **技术栈** | FastAPI + secrets + hashlib + React Router |
| **核心逻辑** | 1. Token 生成：256 位熵<br>2. Token 存储：SHA-256 哈希（不存明文）<br>3. 一次性使用：设置密码后立即失效<br>4. 24 小时过期<br>5. 限流：每小时最多 5 次 |
| **输入输出** | **输入**：`{token, password, password_confirm}`<br>**输出**：`{message: "密码设置成功"}` |
| **关键配置** | `PASSWORD_TOKEN_EXPIRE_HOURS=24`、Token 限流 5 次/小时 |

### 1.3 用户登录

| 项目 | 说明 |
|------|------|
| **功能名称** | 用户登录（用户名/邮箱双模式） |
| **功能作用** | 支持用户名和邮箱两种方式登录，返回 JWT Access Token 和 Refresh Token |
| **后端实现** | 路由：`app/api/routes/auth.py`；认证模块：`app/core/security.py`；依赖注入：`app/api/deps.py` get_current_user |
| **前端实现** | 页面：`src/pages/LoginPage.tsx`；状态管理：`src/store/authStore.ts`（Zustand）；API 封装：`src/api/auth.ts`；Token 持久化：localStorage |
| **技术栈** | FastAPI + JWT(HS256) + bcrypt + React + Zustand + localStorage |
| **核心逻辑** | 1. 同时查询 `User.username` 和 `User.email`（前端 email 字段作为 username 发送）<br>2. 密码 bcrypt 校验<br>3. 登录失败计数 + 锁定（5 次失败锁定 15 分钟）<br>4. 签发 JWT（Access 15 分钟，Refresh 7 天） |
| **输入输出** | **输入**：`{username, password}`（username 字段可填邮箱）<br>**输出**：`{access_token, refresh_token, token_type, user: {id, username, email, user_type}}` |
| **关键配置** | `ACCESS_TOKEN_EXPIRE_MINUTES=15`、`REFRESH_TOKEN_EXPIRE_DAYS=7`、`LOGIN_FAILURE_LOCK_THRESHOLD=5`、`LOGIN_FAILURE_LOCK_MINUTES=15`、`UserLogin.username` max_length=100 |

### 1.4 游客登录（临时登录）

| 项目 | 说明 |
|------|------|
| **功能名称** | 游客临时登录 |
| **功能作用** | 提供游客登录入口，无需注册即可体验，但限制为 20 次提问，仅可访问公共文档库，不可上传文档 |
| **后端实现** | 路由：`auth.py` guest-login；提问计数：`chat.py` + Redis；上传限制：`documents.py` 用 `get_current_regular_user` 依赖保护 |
| **前端实现** | 页面：`LoginPage.tsx` 游客按钮；状态：`authStore.ts`（user_type='guest'）；文档页：`DocumentsPage.tsx` 隐藏上传入口显示"游客无权提交"提示 |
| **技术栈** | FastAPI + Redis 计数器 + React 条件渲染 |
| **核心逻辑** | 1. 创建 guest 类型用户（`user_type='guest'`）<br>2. Redis 计数器：`guest:questions:{user_id}`，TTL 24 小时<br>3. 每次提问成功后 +1，达到 20 次返回 429<br>4. 文档上传/URL 导入接口拒绝 guest 用户 |
| **输入输出** | **输入**：无（一键登录）<br>**输出**：`{access_token, user: {user_type: "guest"}}` |
| **关键配置** | Guest 提问上限 20 次、Redis TTL 24 小时、`user_type` 字段（regular/guest） |

### 1.5 Token 刷新与登出

| 项目 | 说明 |
|------|------|
| **功能名称** | Token 刷新与登出 |

| **输入输出** | **输入**：`{refresh_token}`<br>**输出**：`{access_token, token_type}` |
| **关键配置** | `SECRET_KEY`、`ALGORITHM=HS256`、Redis 黑名单 TTL |

|------|------|
| **功能名称** | 关键词检索（中文 bigram + 英文全文检索） |

| **前端实现** | 无独立 UI（结果体现在回答来源中） |

| **输入输出** | **输入**：`{query, top_k, document_ids}`<br>**输出**：`[{chunk_id, content, keyword_score}]` |

### 5.3 混合检索（加权融合）

| 项目 | 说明 |
|------|------|

| **功能作用** | 结合向量检索和关键词检索，加权融合两路结果 |
| **后端实现** | 服务：`vector_store.py` search() |
| **前端实现** | 无独立 UI（结果体现在回答来源中） |
